# 金融市場における極値統計学（EVT）分析

このリポジトリは、Pythonを用いて金融市場データにおける極端なイベント（テールリスク）を分析するためのスクリプトです。極値統計学（Extreme Value Theory, EVT）の一手法であるピーク超過法（Peaks Over Threshold, POT）と一般化パレート分布（Generalized Pareto Distribution, GPD）を利用しています。

## 概要

金融市場のリターンは正規分布に従わず、「ファットテール」と呼ばれる極端なイベントが理論上の想定より頻繁に発生する特性を持ちます。このスクリプトは、過去の市場データから極端な損失が発生する確率と規模をモデル化し、特定のショックシナリオが「何年に一度の損失か」（リターンピリオド）を推定します。

具体的には、以下の処理を実行します。
1.  ExcelファイルからNIKKEIまたはTOPIXの時系列データを読み込みます。
2.  指定した閾値（上位5%の損失）を超えるデータを抽出し、GPDを適合させてテール領域の分布形状（`xi`）とスケール（`beta`）を推定します。
3.  推定したEVTモデル、および比較対象として正規分布とt分布モデルを使用し、特定のショックシナリオのリターンピリオドを計算します。
4.  分析の妥当性を評価するための4つの診断プロット（MRLプロット, QQプロット, リターンレベルプロット, 密度プロット）を自動生成し、ファイルに保存します。

-   `matplotlib`

```bash
pip install numpy pandas scipy matplotlib openpyxl
```

## 使い方

### 1. データ準備

`data/index_values.xlsx` という名前でExcelファイルを配置します。このファイルには、日付をインデックスとし、`NIKKEI` と `TOPIX` の列を持つ時系列データを含める必要があります。

### 2. スクリプトの実行

コマンドラインから`evt.py`を実行します。実行時に引数を指定することで、分析対象のインデックスやデータ期間を柔軟に変更できます。

**デフォルトで実行**
（対象: NIKKEI, データ期間: 2000年以降）
```bash
python evt.py
```

**分析対象と期間を指定して実行**
（対象: TOPIX, データ期間: 1990年以降）
```bash
python evt.py --index TOPIX --start-year 1990
```

**利用可能な引数**

`--help` オプションで引数の詳細を確認できます。
```bash
python evt.py --help
```
```
usage: evt.py [-h] [--index {NIKKEI,TOPIX}] [--start-year START_YEAR]

金融市場データに対する極値分析（EVT）を実行します。

options:
  -h, --help            show this help message and exit
  --index {NIKKEI,TOPIX}
                        分析対象のインデックス名 (デフォルト: NIKKEI)
  --start-year START_YEAR
                        分析に使用するデータの開始年 (デフォルト: 2000)
```

## 出力

### コンソール

分析結果として、各ショックシナリオの実損失と、各モデル（EVT, 正規分布, t分布）で計算されたリターンピリオドが出力されます。

```
================================================================================
ショックシナリオ分析
================================================================================
イベント                   | 実損失   | Xi (EVT)     | リターンピリオド (EVT) | リターンピリオド (正規分布)   | リターンピリオド (t分布)
--------------------------------------------------------------------------------
BoJ Shock Scenario       |   -8.2% | 0.150        | 35.8 年              | 1533.1 年             | 40.5 年
--------------------------------------------------------------------------------
...
```
*(注: 上記の数値は実行例であり、実際のデータや期間によって変動します)*

### 診断プロット

分析対象のインデックスとシナリオごとに、4つの診断プロットが `output` ディレクトリに `PNG` ファイルとして保存されます。

-   **Mean Residual Life Plot**: 閾値選択の妥当性を視覚的に確認します。
-   **QQ Plot**: モデル（GPD）が実データにどれだけ適合しているかを確認します。
-   **Return Level Plot**: モデルが予測するリターンピリオドと損失規模の関係を示します。
-   **Density Plot**: 閾値超過データのヒストグラムと、適合したGPDの確率密度関数を比較します。
