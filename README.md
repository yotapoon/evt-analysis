# 金融市場における極値統計学（EVT）分析

このリポジトリは、Pythonを用いて金融市場データにおける極端なイベント（テールリスク）を分析するためのスクリプトです。極値統計学（Extreme Value Theory, EVT）の一手法であるピーク超過法（Peaks Over Threshold, POT）と一般化パレート分布（Generalized Pareto Distribution, GPD）を利用しています。

## 概要

金融市場のリターンは正規分布に従わず、「ファットテール」と呼ばれる極端なイベントが理論上の想定より頻繁に発生する特性を持ちます。このスクリプトは、過去のデータから極端な損失が発生する確率と規模をモデル化し、将来の大きなショック（例：「100年に一度の損失」）がどの程度の規模になるかを推定します。

具体的には、以下の処理を実行します。
1.  t分布と意図的なショックイベントを含む、ファットテールな市場リターン（日次）のダミーデータを生成します。
2.  指定した閾値（例：上位5%の損失）を超えるデータを抽出し、GPDを適合させてテール領域の分布形状（`xi`）とスケール（`beta`）を推定します。
3.  推定したモデルを使い、特定の巨大な損失イベントが「何年に一度のイベントか」（再現期間）を計算します。
4.  分析の妥当性を評価するための診断プロット（MRLプロット, QQプロット, 再現レベルプロット）を可視化します。

## ファイル構成

-   `evt.py`: メインの分析スクリプト

## 実行方法

Python環境で必要なライブラリをインストールした後、スクリプトを実行します。

```bash
pip install numpy pandas scipy matplotlib
python evt.py
```

実行すると、コンソールに各ショックイベントの分析結果が出力され、イベントごとに診断プロットが表示されます。

### 出力例（コンソール）

```
Event                | Loss     | Xi (Tail)       | 95% CI for Xi      | Return Period
------------------------------------------------------------------------------------------
BoJ Shock (2024)     |   12.4% | 0.358 (SE:0.110)  | [0.14, 0.57]       | 139.7 Years
Trump Shock (2025)   |   15.0% | 0.380 (SE:0.108)  | [0.17, 0.59]       | 355.9 Years
```

### 出力例（プロット）

各イベントに対して、以下の3つのプロットが生成されます。

1.  **Mean Residual Life Plot**: 閾値選択の妥当性を視覚的に確認します。線形性が始まるあたりが適切な閾値の候補となります。
2.  **QQ Plot**: モデルが実データにどれだけ適合しているかを確認します。点が赤線上に並ぶほど、モデルの適合度が高いことを示します。
3.  **Return Level Plot**: モデルが予測する「再現期間」と「損失の大きさ」の関係を示します。実際のショックがこの曲線上のどこに位置するかを確認することで、そのイベントの極端性を評価します。

## コードの主要コンポーネント

-   `generate_market_data()`: 分析用のダミーデータを生成します。
-   `EVTAnalyzer` (class): EVT分析を実行するコアクラス。
    -   `fit()`: GPDパラメータを最尤法で推定します。
    -   `calculate_return_period()`: 損失額から再現期間を計算します。
-   `plot_evt_diagnostics()`: 分析結果の診断プロットを描画します。
-   メイン実行ブロック: ウォークフォワード方式で、各ショックイベントが発生する前日までのデータを用いてモデルを構築し、イベントを評価します。これにより、未来の情報を使って過去を評価する「先読みバイアス」を排除しています。
